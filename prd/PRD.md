# PRD: Hello World — 多语言艺术问候页

- **Project ID:** hello-world
- **Version:** 1.0
- **Status:** Draft

## 1. 概述

构建一个极简但视觉惊艳的单页网站，核心功能是用 **20 种语言** 展示"你好"，每种语言以独特的艺术字体/排版呈现。作为研发团队矩阵的验证型项目（hello-world MVP）。

## 2. 目标

1. 验证从 PRD → 实现 → 门禁 → 预览的完整研发流水线
2. 产出可部署的 HTML 页面，可直接通过 `python3 -m http.server` 或任意静态服务器托管
3. 视觉上具有展示价值

### F-2: 艺术字排版

每条问候语必须使用区别于其他条目的字体风格/排版效果。效果可包括：

- 渐变文字、霓虹光效、毛玻璃、阴影/3D 立体
- 书法/手写、衬线/无衬线、装饰性字体
- 动态动画（悬浮、渐入、呼吸光效）

### F-3: 响应式布局

- 桌面：网格布局（4-5 列）
- 平板：3 列
- 手机：1-2 列

### F-4: 交互

- 鼠标悬停时高亮/放大效果
- 页面标题显示 "🌍 Hello World — 20 Languages"

## 4. 非功能需求

- 单文件 HTML（无构建工具、无外部依赖）
- 使用 Google Fonts CDN 加载字体
- 页面加载时间 < 2s（良好网络条件下）

## 5. 验收标准

- [ ] 所有 20 种语言正确显示
- [ ] 每种语言问候使用唯一艺术字风格
- [ ] 响应式布局（桌面/平板/手机）
- [ ] 悬停交互生效
- [ ] 单文件 `index.html`，可直接打开或通过静态服务器托管

## 6. 技术选型

| 项目 | 选择 |
|------|------|
| 语言 | HTML + CSS + Vanilla JS |
| 字体 | Google Fonts（每种语言匹配对应字体） |
| 部署 | `python3 -m http.server 8080` |
| 框架 | 无 |
